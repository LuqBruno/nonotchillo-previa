# Nono Tchillo · prévia conceitual

Página estática em português brasileiro, sem compilação nem dependências em execução.

- `index.html` tem textos, fotos e links.
- `style.css` define tema, recortes, layouts e estados estáticos.
- `app.js` liga toalha e fotos à rolagem nativa. Deslizar horizontalmente sobre a foto no celular muda de ocasião.
- `assets/` contém as fotos otimizadas, as fontes e o monograma.

Para revisar na raiz da operação, use `node 03_Empresa_Interna/06_Producao/op.mjs previa Nono_Tchillo --porta 4532`. Também funciona com um servidor HTTP estático apontado para esta pasta.

A prévia usa URLs relativas, `noindex`, sinalização conceitual e o monograma BL. Fontes das fotos e versão dos recortes constam na documentação local do projeto.
